Insurance platform

Reducing errors in a compliance-critical workflow

Role
UX Designer
Team
Business analysts, developers, PMs, international client teams
Scope
User flows · Wireframes · Prototyping · UI redesign · Accessibility (WCAG)
Platform
Web application

Context

Insurance agents must manually update Customer Reference Numbers (CRNs) every three months to meet regulatory and integration requirements. The task is simple, but timely and accurate updates are essential for data quality and compliance.

Problem

The process lacked visibility, guidance and feedback, making a routine task error-prone. Key issues:

  • Missed deadlines — no CRN expiration reminders
  • Input errors — no real-time validation or clear error states
  • Limited feedback after submission
  • An outdated UI that did not meet WCAG guidelines

Design challenge

How might we design a reliable CRN update workflow that supports compliance while reducing user errors and uncertainty?

Results

Regulatory and system constraints meant the underlying workflow couldn't change — so the project focused on the experience: a refreshed, WCAG-compliant interface with proactive reminders, validation and clear feedback. The workflow became more transparent, accessible and predictable, reducing errors and increasing user confidence.
